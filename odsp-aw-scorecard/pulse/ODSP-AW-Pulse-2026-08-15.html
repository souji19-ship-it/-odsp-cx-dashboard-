2P ODSP Integration: This Week's Story

ODSP is already a meaningful substrate for M365 agents calling OneDrive and SharePoint before the architecture converges on direct MCP and WorkIQ-routed MCP.

Adoption

Reach grew in Cowork while Copilot Studio / Dracarys accelerated

Cowork users increased +6% and tenants +6%. Copilot Studio / Dracarys users increased +30%, while tenants +16% and active agents +18% also expanded.

Why it matters: ODSP already reaches meaningful populations across both workloads, creating a base for repeat use and customer outcomes.

Engagement

Execution accelerated across both workloads, led by Studio tool calls

Cowork ODSP-backed tasks increased +18% and tool calls +11%. Copilot Studio / Dracarys tasks increased +44%, tool calls +337% and knowledge searches +26%.

Why it matters: activity is growing across execution and grounding; scenario mix and completed outcomes now need to show which growth creates customer value.

Reliability

ODSP tool success remained high across both 2P workloads

Cowork ODSP tool success was 95.6%, moving -0.2 pp week over week. Copilot Studio / Dracarys ODSP tool success was 92.7%, moving +0.5 pp.

Why it matters: the baseline is strong enough to focus on outcome depth while continuing to segment service-owned and caller-owned failures.

Architecture runway

Today's bespoke integrations establish the pre-MCP baseline

Current Cowork and Copilot Studio / Dracarys measurements describe bespoke Graph API and connector paths. Direct SharePoint MCP and WorkIQ-routed SharePoint/OneDrive MCP require explicit route attribution.

Why it matters: route-level telemetry must distinguish Graph API, direct MCP and WorkIQ-routed MCP so adoption, engagement and reliability remain comparable through the transition.

Leadership watch

Growth was broad, but Studio tool calls need a driver check

Copilot Studio / Dracarys tool calls jumped +337% week over week, directionally consistent with +44% tasks and +18% agents, but the magnitude warrants a root-cause before it reads as trend. Cowork's 14% tool-call figure remains the governed mean-daily penetration lens, not a fixed-week broad-share substitute.

Why it matters: leadership should watch which scenarios generate the higher event intensity and whether those scenarios complete valuable customer work.

Overall

ODSP combines broad reach, growing execution and strong reliability

The 2P footprint spans Cowork reach, Copilot Studio / Dracarys expansion, increasing ODSP-backed work and a measurable pre-MCP reliability baseline.

Why it matters: the next step is converting this footprint into repeatable high-value scenarios while instrumenting the move from bespoke Graph paths to direct MCP and WorkIQ-routed MCP.

Methodology

Adoption

Active Users: Count of 2P agent users who used at least one ODSP tool.

Active Tenants: Count of 2P agent tenants where at least one ODSP tool was used.

Active Agents: Count of 2P agents that used at least one ODSP tool.

Engagement

Tasks: Count of 2P agent tasks in which at least one ODSP tool contributed to task execution.

Tool Calls: Count of 2P agent tool calls that leveraged an ODSP tool.

Knowledge Searches: Count of 2P agent knowledge searches that leveraged an ODSP knowledge source.

Reliability

Tool Success Rate: Percentage of eligible ODSP tool calls that completed successfully under the surface-native reliability definition.
