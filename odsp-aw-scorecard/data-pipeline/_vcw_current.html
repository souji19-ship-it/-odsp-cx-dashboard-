Performance & Task Success — Definitions DEFINITIONS
MetricHow it is calculated
Total TasksAll ODSP-in-Cowork tasks in the window — tasks where the SharePoint+OneDrive plugin was invoked ≥1.
Completed TasksTasks that produced a final response — Clean + Recovered.
Clean tasks / successFinal response with zero tool failures. Rate = clean ÷ total tasks.
Recovered tasksFinal response despite ≥1 tool failure (agent worked around it).
Poisoned (failed)Tasks with no good final response. Failure rate = poisoned ÷ total tasks.
Overall task successAny successful final response (Clean + Recovered) ÷ total tasks — includes recoveries.
Recovery rateRecovered ÷ (Recovered + Poisoned) — share of failed-tool tasks that still delivered.
Turn success ratePer-turn success across all turns in the slice (turn-level, not task-level).
Tool success rateSuccessful ODSP tool calls ÷ total ODSP tool calls (SharePoint/OneDrive service dependency).
Avg latencyMean server-side latency per ODSP tool call, in ms (lower = faster).
WoWCounts: (This − Last) ÷ Last. Rates: percentage-point delta (pp). Latency: % faster/slower.
Source: Cowork Tools dashboard → Task success tab (SharePoint/OneDrive plugin invoked ≥1). Surface Split — Definitions DEFINITIONS
MetricHow it is calculated
SurfaceDerived from the tool name. OneDrive tools → OneDrive, SharePoint tools → SharePoint. Shared (ReadFileContent / CreateFolder) applies to either file type and is tracked separately.
Tasks on surfaceTasks that called ≥1 tool on this surface. A task counts toward every surface it touched, so surfaces overlap and do not sum to the plugin total.
Clean tasksFinal response with zero tool failures on this surface. Rate = clean ÷ tasks touching.
Recovered tasksFinal response despite ≥1 tool failure on this surface (agent worked around it).
Poisoned (failed)Tasks with no good final response on this surface.
Tool callsTotal ODSP tool calls attributed to this surface in the window.
Clean task successClean ÷ tasks touching — final response with no tool failures.
Overall task success(Clean + Recovered) ÷ tasks touching — any successful final response, includes recoveries.
Recovered successRecovered ÷ tasks touching — the recovery lift (overall − clean) in pp.
Recovery rateRecovered ÷ (Recovered + Poisoned) — share of failed-tool tasks that still delivered.
WoWCounts: (This − Last) ÷ Last. Rates: percentage-point delta (pp).
Source: Cowork Tools dashboard → Surface mix (SharePoint+OneDrive plugin, surface derived from tool name). Jul 19–25 → Jul 26–Aug 1. Shared (~44–51% of tool calls) tracked but shown separately; surfaces overlap and do not sum to the plugin total.
